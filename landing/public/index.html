Today, AI lives in an app or a browser tab. You ask, it answers, you do the work. Tripppin puts the model inside the computer, so the model does the work.

01 / what it does

Say it once.
It handles the rest.

Every line is a request

The terminal and a floating orb take plain sentences. "Free up some space." "Share this folder." "Install a photo editor."

The OS is the toolbox

Files, apps, network, settings and the web are skills the AI can use, each one sandboxed and typed.

The classic shell stays

Start a line with ! to run a command exactly as typed, or switch the tab to a normal terminal with /term.

02 / safety

A second opinion.
Before anything risky.

You shouldn't have to approve everything. A separate AI check, the verifier, compares each risky action with what you actually asked for.

The verifier never reads page or file text, so hidden instructions there can't talk it into anything.

Ask

You approve every change yourself.

Autodefault

The verifier approves routine changes. When it isn't sure, you decide.

YOLO

Never asks. Raw commands and anything prompted by outside content still get verified.

Undo is built in

Installs, settings and file changes are snapshotted first. One command rolls them back.

Secrets stay secret

Keys and private folders are off limits to every tool, in every mode.

Every part, listed

trip bom shows every package, its version, its license and any security issue.
