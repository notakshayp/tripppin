01 / basics

OS, kernel, distro.
Three words, one house.

The kernel is the plumbing. The operating system is the whole house. A distro is one builder's version of that house. Tripppin is ours.

A distro is a custom OS. We don't write the kernel or the thousands of basic programs. We pick them, configure them, add our AI layer on top and ship one installer file (an .iso).

04 / harness

Small models are messy.
The harness isn't.

The model never types Linux commands. It picks from a short menu of typed tools, and every step is checked.

Route

Fast rules sort the request. Milliseconds, no big model.

Pick tools

Only 5–15 relevant tools, with a cached prompt.

Constrain

A grammar makes invalid tool calls impossible.

Validate

Paths, packages and addresses checked against reality.

Verify

A second AI asks: "Did the person ask for this?"

Preview

What will happen, in plain words.

Execute

Inside a sandbox the harness chose.

Answer

Streamed live. Ctrl-C cancels anytime.

Shell is the last resort

shell.run exists, and always goes through the verifier.

Each model's own format

Qwen3.5 speaks XML tool calls, so it gets an XML grammar.

You come first

Background agents pause when you ask something.

A test suite of a few hundred real requests and attacks scores every model and every change: right tool, right arguments, job done, speed, and how often the verifier gets it wrong. Nothing that scores worse ships.

08 / safety

A second opinion.
Before anything risky.

You shouldn't have to approve everything. A separate AI check, the verifier, reviews risky actions for you.

The verifier never sees page or file text, so hidden instructions there can't talk it into anything.

Ask

You approve every change. The verifier adds its opinion.

Autodefault

The verifier approves routine changes. Unsure means you decide.

YOLO

Never asks. Shell commands and anything prompted by outside content still go through the verifier.

Hard rules under the verifier

Outside content is tracked

After a web page or file enters a chat, every change is verified.

Secrets are off limits

~/.ssh, keys and the keyring can't be read by tools.

No quiet leaks

Only addresses you typed or a search returned.

Narrow admin

Specific actions only. Approval never cached.

Sealed log

Every action recorded. The AI can't edit it.

Block list

A few actions, like wiping a disk, never run.

Can be undone

  • Installing or removing apps
  • Changing settings
  • Moving or deleting your files

Can't be undone, always verified

  • Sending or sharing a file
  • Anything sent to a website
  • Anything sent to a cloud service

trip undo works without the AI, and a rescue entry in the boot menu starts a system with no AI at all.

15 / words

Glossary.

Model, weights
The AI itself. Weights are the file holding what it learned.
4B, 9B, 27B
Billions of parameters, roughly the model's size.
MoE, "35B-A3B"
A big model that uses only a small part per word, so it's fast.
Token
A piece of a word. 1,000 tokens is about 750 words.
Tool call
The model asking the system to do one specific thing.
Verifier
A second AI check that compares an action with what you asked.
Grammar
Rules that limit what the model can write.
MCP
A shared standard for describing tools to AI models.
Prompt injection
Hidden instructions in a page or file that try to trick the AI.
Snapshot
A saved copy of the system for going back in time.
SearXNG
Open-source search that asks several engines at once.
SBOM
A standard list of every component and its license.
